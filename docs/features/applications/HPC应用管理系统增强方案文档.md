## 📋 项目概述

基于对HPC平台模板编辑功能的深入分析，本方案为当前应用管理系统引入了现代化的模板编辑能力，显著提升了HPC应用配置的用户体验和管理效率。

## 🎯 核心目标

### 主要改进目标
- **模板化管理**：引入HPC平台的模板编辑最佳实践
- **可视化编辑**：提供拖拽式表单构建界面
- **向导式配置**：简化复杂应用的配置流程
- **版本控制**：实现应用配置的版本管理
- **用户体验**：现代化的交互设计和操作流程

### 参考平台特色
通过分析 `https://192.168.31.175:8443/#/template` 的HPC平台模板系统，提取了以下核心特色：
- 拖拽式表单构建器
- 实时预览功能
- 模板参数化配置
- 版本控制和权限管理
- 分步骤配置向导

## 🚀 核心功能模块

### 1. 高级模板构建器 (`template-builder.tsx`)

#### 功能特性
- **三栏式布局**：字段模板库 + 表单构建器 + 属性编辑器
- **拖拽交互**：基于 `@hello-pangea/dnd` 的拖拽排序
- **实时预览**：即时查看表单效果
- **字段类型**：支持文本、数字、文件、下拉、复选框等

#### 核心组件
```typescript
interface TemplateBuilderProps {
  formFields: FormField[]
  onFieldsChange: (fields: FormField[]) => void
  isPreviewMode?: boolean
  onPreviewToggle?: (isPreview: boolean) => void
}
```

#### 技术亮点
- 模块化设计，组件高度复用
- 支持预览/编辑模式切换
- 拖拽手柄和属性编辑分离
- 字段模板库可扩展

### 2. 应用配置向导 (`application-wizard.tsx`)

#### 向导步骤
1. **基本信息**：应用名称、版本、分类、描述
2. **用户界面**：表单字段配置
3. **执行配置**：脚本模板和资源配置
4. **权限设置**：可见性和访问控制

#### 功能特性
- **进度指示**：可视化步骤进度条
- **数据同步**：实时保存配置状态
- **验证机制**：每步必填项验证
- **导航控制**：支持前进、后退、跳转

#### 核心接口
```typescript
interface ApplicationWizardProps {
  application?: HpcApplicationSpec
  onSave: (app: HpcApplicationSpec) => void
  onCancel: () => void
  isNewApplication?: boolean
}
```

### 3. 版本管理系统 (`version-manager.tsx`)

#### 版本状态
- **active**：当前活跃版本
- **draft**：草稿状态
- **deprecated**：已弃用
- **archived**：已归档

#### 功能特性
- **版本历史**：完整的变更记录
- **变更日志**：详细的修改说明
- **版本比较**：不同版本间的差异对比
- **发布流程**：草稿→发布的工作流

#### 数据结构
```typescript
interface ApplicationVersion {
  id: string
  version: string
  name: string
  displayName?: string
  description: string
  author: string
  createdAt: string
  status: 'active' | 'draft' | 'deprecated' | 'archived'
  changes: string[]
  isPublic: boolean
  parentVersion?: string
}
```

## 🚦 使用指南

### 快速开始
1. **访问应用管理**：导航至 `/dashboard/system/applications/management`
2. **选择应用**：点击应用卡片进入详情页面
3. **选择模式**：根据需求选择不同的编辑模式

### 功能使用

#### 高级模板构建器
```
1. 点击"高级构建器"标签页
2. 从左侧模板库拖拽字段类型
3. 在中央构建器调整字段顺序
4. 在右侧属性面板编辑字段属性
5. 切换预览模式查看效果
```

#### 应用配置向导
```
1. 点击"向导模式"按钮
2. 按步骤完成各项配置：
   - 基本信息：名称、版本、描述
   - 用户界面：表单字段设计
   - 执行配置：脚本模板设置
   - 权限设置：访问控制配置
3. 最后一步保存应用
```

#### 版本管理
```
1. 点击"版本管理"按钮
2. 查看版本历史和变更记录
3. 创建新版本或基于现有版本复制
4. 管理版本状态（草稿/发布/归档）
```
