# 作业同步机制测试指南

## 测试步骤

### 1. 页面加载测试

**测试目标：** 验证页面加载时的自动同步功能

**测试步骤：**
1. 打开 `/dashboard/jobs` 页面
2. 观察控制台日志，应该看到：
   ```
   发现 X 个活跃作业，优先同步...
   活跃作业同步完成: {stats: {...}}
   执行完整同步（最近7天所有作业）...
   完整同步完成: {stats: {...}}
   ```
3. 检查页面状态显示：
   - 活跃作业数量显示
   - 上次同步时间显示
   - 同步按钮状态

**预期结果：**
- 页面快速加载并显示作业列表
- 后台自动执行同步
- 同步完成后状态更新

### 2. 智能同步测试

**测试目标：** 验证智能同步按钮功能

**测试步骤：**
1. 点击"智能同步"按钮
2. 观察按钮状态变化（显示"同步中..."）
3. 等待同步完成
4. 检查toast提示信息

**预期结果：**
- 按钮显示加载状态
- 同步完成后显示更新数量
- 作业列表自动刷新

### 3. 强制同步测试

**测试目标：** 验证强制同步按钮功能

**测试步骤：**
1. 点击"强制同步"按钮
2. 观察同步过程
3. 检查是否同步了所有作业（包括历史作业）

**预期结果：**
- 执行完整同步（最近7天所有作业）
- 更新包括已完成、失败、取消的作业状态
- 显示详细的同步统计信息

### 4. 自动同步测试

**测试目标：** 验证后台自动同步功能

**测试步骤：**
1. 保持页面打开
2. 等待5秒后观察是否启动自动同步
3. 切换页面标签页，再切换回来
4. 观察是否重新启动同步

**预期结果：**
- 5秒后自动启动同步
- 页面隐藏时停止同步
- 页面显示时重新启动同步

### 5. 错误处理测试

**测试目标：** 验证同步失败时的错误处理

**测试步骤：**
1. 模拟网络错误（断开网络连接）
2. 尝试执行同步
3. 检查错误提示和降级处理

**预期结果：**
- 显示友好的错误提示
- 降级到数据库数据
- 不影响页面基本功能

## 常见问题

### 1. 同步不工作
**可能原因：**
- Slurm服务未运行
- 网络连接问题
- 权限不足

**解决方法：**
- 检查Slurm服务状态
- 验证网络连接
- 检查API权限

### 2. 同步速度慢
**可能原因：**
- 作业数量过多
- 网络延迟
- 数据库性能问题

**解决方法：**
- 减少同步时间范围
- 优化网络连接
- 检查数据库性能

### 3. 状态不准确
**可能原因：**
- 状态映射错误
- 同步失败
- 缓存问题

**解决方法：**
- 检查状态映射逻辑
- 重新执行同步
- 清除缓存
