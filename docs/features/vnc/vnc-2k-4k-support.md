# VNC系统2K和4K分辨率支持

> 适用范围：功能模块长期知识（WebShell、VNC、应用中心等）
> 主入口链接：`docs/README.md`
> 文档状态：`active`
> 最后验证日期：`2026-03-27`

## 🎯 功能概述

VNC系统现已支持2K和4K高分辨率显示，为用户提供更好的视觉体验和更大的工作空间。

## ✅ 新增分辨率选项

### 支持的分辨率列表

| 分辨率 | 标签 | 适用场景 |
|--------|------|----------|
| 1024x768 | XGA | 基础显示，兼容性好 |
| 1280x800 | WXGA | 宽屏笔记本 |
| 1280x1024 | SXGA | 传统4:3显示器 |
| 1440x900 | WXGA+ | 宽屏显示器 |
| 1600x900 | HD+ | 高清宽屏 |
| **1920x1080** | **Full HD** | **默认推荐** |
| **2560x1440** | **2K QHD** | **高分辨率工作** |
| **3840x2160** | **4K UHD** | **超高分辨率显示** |

### 新增的高分辨率选项

1. **2K QHD (2560x1440)**
   - 适合：专业设计、开发工作、多窗口操作
   - 优势：更大的工作空间，更清晰的文字显示
   - 性能：中等资源消耗

2. **4K UHD (3840x2160)**
   - 适合：超高分辨率需求、专业图形工作、大屏显示
   - 优势：极致的清晰度和细节表现
   - 性能：较高资源消耗，需要良好的网络带宽

## 🔧 技术实现

### 1. 配置文件修改

**文件：** `lib/builtin-vnc-apps.ts`
```typescript
options: [
  { value: '1024x768', label: '1024x768 (XGA)' },
  { value: '1280x800', label: '1280x800 (WXGA)' },
  { value: '1280x1024', label: '1280x1024 (SXGA)' },
  { value: '1440x900', label: '1440x900 (WXGA+)' },
  { value: '1600x900', label: '1600x900 (HD+)' },
  { value: '1920x1080', label: '1920x1080 (Full HD)' },
  { value: '2560x1440', label: '2560x1440 (2K QHD)' },
  { value: '3840x2160', label: '3840x2160 (4K UHD)' }
]
```

**文件：** `lib/vnc-manager.ts`
```typescript
const VNC_CONFIG = {
  DEFAULT_GEOMETRY: '1920x1080', // 更新默认分辨率
  // ... 其他配置
}
```

### 2. VNC脚本生成

VNC脚本会自动使用选择的分辨率启动TurboVNC服务器：

```bash
# 启动 TurboVNC Server
${VNC_CONFIG.TURBO_VNC_PATH}vncserver :${display} -geometry ${geometry} -SecurityTypes ${VNC_CONFIG.SECURITY_TYPE}
```

## 🚀 使用方法

### 1. 启动VNC桌面会话

1. 访问 **应用中心**：`/dashboard/applications/vnc`
2. 点击 **"系统桌面"** 应用
3. 在分辨率下拉菜单中选择：
   - **2K QHD (2560x1440)** - 高分辨率工作
   - **4K UHD (3840x2160)** - 超高分辨率显示
4. 点击 **"启动桌面会话"**

### 2. 配置建议

#### 2K分辨率 (2560x1440)
- **适用场景**：专业开发、设计工作、多窗口操作
- **网络要求**：稳定的网络连接
- **客户端要求**：支持2K显示的显示器

#### 4K分辨率 (3840x2160)
- **适用场景**：超高分辨率需求、专业图形工作
- **网络要求**：高速稳定的网络连接
- **客户端要求**：4K显示器，高性能客户端设备

## 📊 性能考虑

### 网络带宽需求

| 分辨率 | 推荐带宽 | 最低带宽 |
|--------|----------|----------|
| 1920x1080 | 10 Mbps | 5 Mbps |
| 2560x1440 | 20 Mbps | 10 Mbps |
| 3840x2160 | 50 Mbps | 25 Mbps |

### 系统资源消耗

- **CPU使用率**：高分辨率会增加编码/解码负载
- **内存使用**：更大的帧缓冲区需求
- **网络延迟**：更高的数据传输量

## 🔍 故障排除

### 1. 高分辨率显示模糊

**可能原因**：
- 客户端显示器不支持该分辨率
- 网络带宽不足
- VNC客户端缩放设置问题

**解决方案**：
- 选择适合客户端显示器的分辨率
- 检查网络连接质量
- 调整VNC客户端显示设置

### 2. 性能问题

**可能原因**：
- 网络带宽不足
- 系统资源不足
- VNC编码设置不当

**解决方案**：
- 降低分辨率
- 检查系统资源使用情况
- 优化VNC编码参数

### 3. 显示异常

**可能原因**：
- 客户端不支持高分辨率
- VNC服务器配置问题

**解决方案**：
- 尝试较低分辨率
- 检查VNC服务器日志
