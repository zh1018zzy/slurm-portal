## 功能概述

文件管理页面现在支持文件过滤功能，可以帮助用户更好地管理和查找文件。

## 过滤功能

### 1. 隐藏文件过滤 🔍

**功能说明：**
- 默认情况下，以点（`.`）开头的隐藏文件会被自动过滤掉
- 用户可以通过复选框控制是否显示隐藏文件

**使用方法：**
1. 在文件列表页面找到"显示隐藏文件"复选框
2. 勾选复选框可以显示所有文件（包括隐藏文件）
3. 取消勾选只显示普通文件

**适用场景：**
- 查看配置文件（如 `.bashrc`, `.gitignore`）
- 查看系统隐藏文件
- 清理隐藏文件

### 2. 文件名搜索 🔍

**功能说明：**
- 支持按文件名进行模糊搜索
- 搜索不区分大小写
- 支持部分匹配

**使用方法：**
1. 在搜索框中输入要查找的文件名
2. 系统会实时过滤显示匹配的文件
3. 清空搜索框可以显示所有文件

**搜索示例：**
- 输入 `log` 可以找到所有包含 "log" 的文件
- 输入 `.txt` 可以找到所有文本文件
- 输入 `test` 可以找到所有包含 "test" 的文件

## 技术实现

### 1. 后端API支持

**新增参数：**
- `showHidden`: 是否显示隐藏文件（true/false）
- `filter`: 文件名过滤条件

**API调用示例：**
```bash
# 显示所有文件（包括隐藏文件）
GET /api/files?username=testuser3&path=&showHidden=true

# 只显示普通文件
GET /api/files?username=testuser3&path=&showHidden=false

# 搜索包含 "log" 的文件
GET /api/files?username=testuser3&path=&filter=log

# 组合使用：搜索隐藏文件中的 "config"
GET /api/files?username=testuser3&path=&showHidden=true&filter=config
```

### 2. 前端实现

**状态管理：**
```typescript
const [showHidden, setShowHidden] = useState(false);
const [filterText, setFilterText] = useState('');
```

**缓存优化：**
- 过滤条件会包含在缓存键中
- 不同过滤条件有独立的缓存
- 过滤条件改变时会清除相关缓存

**防抖处理：**
- 搜索输入有300ms防抖
- 避免频繁的API请求
- 提升用户体验

## 性能优化

### 1. 缓存策略
- 每个过滤组合都有独立的缓存
- 缓存键格式：`${username}-${path}-${showHidden}-${filter}`
- 30秒缓存时间，平衡性能和实时性

### 2. 防抖机制
- 搜索输入防抖：300ms
- 避免用户快速输入时的频繁请求
- 减少服务器负载

### 3. 智能缓存清理
- 过滤条件改变时自动清理缓存
- 确保显示最新结果
- 避免显示过期的过滤结果

## 常见使用场景

### 1. 查看配置文件
```
1. 勾选"显示隐藏文件"
2. 搜索 "config" 或 "rc"
3. 找到相关配置文件
```

### 2. 清理临时文件
```
1. 搜索 "tmp" 或 "temp"
2. 批量选择临时文件
3. 执行批量删除
```

### 3. 查找日志文件
```
1. 搜索 "log" 或 ".log"
2. 查看日志文件大小和修改时间
3. 决定是否需要清理
```

## 注意事项

### 1. 性能考虑
- 大量文件时搜索可能较慢
- 建议使用更具体的搜索词
- 避免在根目录进行模糊搜索

### 2. 安全提醒
- 隐藏文件通常包含重要配置
- 删除前请确认文件用途
- 建议先备份重要文件

### 3. 缓存机制
- 过滤结果会被缓存30秒
- 如果文件有更新，可能需要刷新页面
- 重要操作后建议清除缓存
