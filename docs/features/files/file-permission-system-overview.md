## 系统简介

文件权限管理系统是一个完整的文件操作权限控制解决方案，允许管理员精确控制用户对文件的访问和操作权限。

## 权限类型

系统支持以下7种文件操作权限：

### 1. 文件上传权限 (`file_upload`)
- **功能**：控制用户是否可以上传文件
- **限制项**：文件大小、类型、配额、路径、时间
- **应用场景**：限制用户上传文件的大小和类型

### 2. 文件下载权限 (`file_download`)
- **功能**：控制用户是否可以下载文件
- **限制项**：文件类型、路径、时间
- **应用场景**：保护敏感文件不被下载

### 3. 文件预览权限 (`file_preview`)
- **功能**：控制用户是否可以预览文件内容
- **限制项**：文件类型、路径、时间
- **应用场景**：允许查看文件但不允许下载

### 4. 文件删除权限 (`file_delete`)
- **功能**：控制用户是否可以删除文件
- **限制项**：路径、时间
- **应用场景**：保护重要文件不被误删

### 5. 文件分享权限 (`file_share`)
- **功能**：控制用户是否可以分享文件
- **限制项**：文件类型、路径、时间
- **应用场景**：控制文件分享功能

### 6. 文件导出权限 (`file_export`)
- **功能**：控制用户是否可以导出文件
- **限制项**：文件类型、路径、时间
- **应用场景**：限制文件导出功能

### 7. 文件复制权限 (`file_copy`) ⭐ 新增
- **功能**：控制用户是否可以复制文件内容
- **限制项**：文本选择、右键菜单、键盘快捷键
- **应用场景**：防止文件内容被复制到剪贴板

## 系统特性

### 1. 精确权限控制
- 支持7种不同的文件操作权限
- 每种权限可以独立启用或禁用
- 支持基于用户、角色、部门的权限分配

### 2. 多种限制选项
- **文件限制**：文件大小、类型、配额
- **路径限制**：允许路径、禁止路径
- **时间限制**：允许时间、允许日期
- **配额控制**：存储空间限制

### 3. 安全特性
- 实时权限验证
- 操作日志记录
- 权限审计功能
- 防路径遍历攻击

### 4. 用户界面
- 直观的权限管理界面
- 实时权限状态显示
- 批量权限操作
- 权限配置向导

## 使用流程

### 1. 管理员操作
1. 访问系统管理 → 文件权限管理
2. 选择要管理的用户
3. 配置相应的文件操作权限
4. 设置权限限制条件
5. 保存权限配置

### 2. 用户操作
1. 用户登录系统
2. 访问文件管理页面
3. 系统根据权限显示/隐藏操作按钮
4. 用户只能执行有权限的文件操作

## 常见问题

### Q: 如何为所有用户批量设置权限？
A: 使用权限管理页面的批量操作功能，可以同时为多个用户设置相同的权限。

### Q: 权限修改后多久生效？
A: 权限修改立即生效，无需重启系统。

### Q: 如何查看用户的权限使用历史？
A: 在系统日志页面可以查看详细的权限使用记录。

### Q: 支持哪些文件类型的权限控制？
A: 系统支持所有文件类型的权限控制，包括文本文件、图片、视频等。
