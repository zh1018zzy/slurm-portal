# WebShell 增强水印功能

> 适用范围：功能模块长期知识（WebShell、VNC、应用中心等）
> 主入口链接：`docs/README.md`
> 文档状态：`active`
> 最后验证日期：`2026-03-27`

## 功能概述

WebShell界面现已集成增强版水印功能，相比普通文件预览水印，提供了更密集、更全面的水印覆盖，确保终端内容的安全性。

## 主要特性

### 1. 密集水印分布

#### 水印数量
- **总计30个水印**：比普通水印（5个）多6倍
- **分层设计**：主要水印、对角线水印、边缘水印
- **全覆盖**：确保终端内容无死角保护

#### 水印分类
1. **主要水印**（9个）：大尺寸，高可见度
2. **对角线水印**（8个）：不同角度，增加识别难度
3. **边缘水印**（11个）：小尺寸，边界覆盖
4. **装饰水印**（2个）：更淡的颜色，增加层次

### 2. 多样化样式

#### 字体大小
- **大尺寸**：24px - 26px（主要水印）
- **中尺寸**：16px - 22px（对角线水印）
- **小尺寸**：12px - 14px（边缘水印）
- **装饰尺寸**：10px（装饰水印）

#### 透明度层次
- **高透明度**：0.5（主要水印）
- **中透明度**：0.25 - 0.4（对角线水印）
- **低透明度**：0.2（边缘水印）
- **装饰透明度**：0.15（装饰水印）

#### 旋转角度
- **标准角度**：-45度（主要水印）
- **变化角度**：-30度、-60度（对角线水印）
- **统一角度**：-45度（边缘水印）

### 3. 智能配置

#### 配置继承
- 完全继承系统设置中的水印配置
- 支持自定义水印文本
- 支持水印开关控制

#### 显示逻辑
1. 系统设置 > 自定义文本 > 用户名
2. 水印开关控制整体显示
3. 动态获取最新配置

```typescript
const watermarkPositions = [

  { top: '50%', left: '50%', fontSize: '26px', opacity: '0.5' },

  { top: '95%', left: '50%', fontSize: '12px', opacity: '0.2' },
];
```

## 安全优势

### 1. 防截图保护
- **密集覆盖**：30个水印确保截图时无法避开
- **多层次**：不同大小和透明度增加识别难度
- **多角度**：不同旋转角度防止简单处理

### 2. 内容溯源
- **用户标识**：清晰显示操作用户
- **时间戳**：通过JWT token包含时间信息
- **操作记录**：便于审计和追踪

### 3. 视觉干扰
- **不影响使用**：透明度适中，不影响终端操作
- **难以去除**：多水印叠加，难以完全清除
- **专业外观**：保持界面美观

## 使用场景

### 1. 安全审计

## 配置方法

### 1. 系统设置配置
1. 访问 `/dashboard/system/settings`
2. 在"安全设置"区域配置水印
3. 设置水印文本（可选）
4. 保存设置

### 2. 配置生效
- 配置立即生效，无需重启
- WebShell和文件预览同时应用
- 所有用户的水印显示都会更新

## 性能优化

### 1. 渲染优化
- 使用CSS transform进行定位
- 避免频繁的DOM操作
- 使用pointer-events: none避免交互干扰

### 2. 内存管理
- 动态生成水印元素
- 及时清理不需要的组件
- 优化重渲染逻辑

### 3. 加载策略
- 动态导入组件，减少初始包大小
- 禁用SSR避免服务端渲染问题
- 使用React的useMemo优化渲染
