# WebShell 水印集成功能

> 适用范围：功能模块长期知识（WebShell、VNC、应用中心等）
> 主入口链接：`docs/README.md`
> 文档状态：`active`
> 最后验证日期：`2026-03-27`

## 功能概述

WebShell 终端页面现已集成水印功能，与文件预览水印使用相同的配置系统，提供一致的安全保护。

## 技术实现

### 1. 组件集成

#### 动态导入水印组件
```typescript
// 动态导入水印组件，禁用SSR
const Watermark = dynamic(() => import('@/components/Watermark'), { 
  ssr: false,
  loading: () => null
})
```

#### 水印应用位置
```typescript
<Watermark username={user?.username || ''}>
  <div className="flex-1 p-2 min-h-0 overflow-hidden">
    {/* 终端内容 */}
    <div ref={terminalRef} className="h-full w-full" />
  </div>
</Watermark>
```

### 2. 配置继承

WebShell 水印功能完全继承系统设置中的水印配置：

- **水印开关**：通过系统设置中的"文件预览水印"开关控制
- **水印文本**：使用系统设置中配置的水印文本
- **显示逻辑**：系统设置 > 自定义文本 > 用户名

### 3. 显示效果

#### 水印样式
- **多水印分布**：在终端区域显示多个水印
- **透明度控制**：不影响终端内容的可读性
- **旋转角度**：-45度旋转，增加识别难度
- **字体样式**：粗体、阴影效果

#### 水印位置
- 左上角区域（1/4 位置）
- 中心位置（1/2 位置）
- 右下角区域（3/4 位置）
- 右上角区域（1/3, 2/3 位置）
- 左下角区域（2/3, 1/3 位置）

## 功能特点

### 1. 一致性
- 与文件预览水印使用相同的配置系统
- 统一的视觉效果和样式
- 相同的启用/禁用逻辑

### 2. 安全性
- 防止终端内容被截图泄露
- 增加内容溯源的难度
- 提供用户身份标识

### 3. 用户体验
- 不影响终端的正常使用
- 水印透明度适中，不影响可读性
- 响应式设计，适配不同屏幕尺寸

## 配置方法

### 1. 系统设置配置
1. 进入 `/dashboard/system/settings` 页面
2. 在"安全设置"区域找到"文件预览水印"
3. 开启水印功能
4. 可选择输入自定义水印文本
5. 保存设置

### 2. 配置生效
- 配置立即生效，无需重启系统
- WebShell 和文件预览页面同时应用新配置
- 所有用户的水印显示都会更新

## 技术细节

### 1. 组件结构
```
WebShellPage
└── WebShellTerminal
    └── Watermark (动态导入)
        └── Terminal Content
```

### 2. 样式处理
- 水印使用绝对定位覆盖在终端内容上方
- 使用 `pointer-events: none` 确保不影响交互
- 通过 CSS 渐变背景增加水印密度

### 3. 性能优化
- 动态导入减少初始包大小
- 禁用 SSR 避免服务端渲染问题
- 使用 React 的 useMemo 优化渲染性能
