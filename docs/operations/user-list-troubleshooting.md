## 问题描述

在权限管理界面中，添加权限的用户下拉列表没有显示所有用户。

## 诊断步骤

### 1. 检查浏览器控制台

1. 打开浏览器开发者工具 (F12)
2. 切换到 Console 标签页
3. 刷新权限管理页面
4. 查看是否有错误信息或调试日志

### 2. 使用调试组件

1. 进入权限管理页面
2. 点击"权限概览"标签页
3. 查看"用户列表调试"组件
4. 点击刷新按钮重新加载用户列表
5. 查看加载状态和错误信息

### 3. 测试API端点

#### 方法1: 浏览器直接访问
```
http://localhost:3000/api/debug/users
```

#### 方法2: 使用curl命令
```bash
curl http://localhost:3000/api/debug/users
```

#### 方法3: 使用测试脚本
```bash
node test-users-api.js
```

## 常见问题和解决方案

### 问题1: API返回404错误

**原因**: API路由不存在或路径错误

**解决方案**:
1. 确认服务器正在运行
2. 检查API文件路径是否正确
3. 重启开发服务器

### 问题2: API返回500错误

**原因**: 数据库连接问题或查询错误

**解决方案**:
1. 检查环境变量配置
2. 确认Supabase连接正常
3. 查看服务器日志

### 问题3: 用户列表为空

**原因**: 数据库中没有用户数据

**解决方案**:
1. 检查数据库中是否有用户数据
2. 确认用户表结构正确
3. 手动添加测试用户

### 问题4: 权限不足

**原因**: 当前用户没有访问权限

**解决方案**:
1. 确认当前用户具有管理员权限
2. 检查JWT令牌是否有效
3. 重新登录系统

## 修复步骤

### 步骤1: 检查环境变量

确保以下环境变量已正确设置:

```bash
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
```

### 步骤2: 检查数据库连接

1. 登录Supabase控制台
2. 检查数据库连接状态
3. 确认用户表存在且有数据

### 步骤3: 检查用户表结构

确保用户表包含以下字段:
- `id` (UUID)
- `username` (VARCHAR)
- `real_name` (VARCHAR)
- `department` (VARCHAR)
- `role` (VARCHAR)

### 步骤4: 重启服务

```bash
# 停止开发服务器
Ctrl+C

# 重新启动
npm run dev
```
