# 系统设置页面布局优化

> 适用范围：线上运行维护、故障排查、部署与运维操作
> 主入口链接：`docs/README.md`
> 文档状态：`active`
> 最后验证日期：`2026-03-27`

## 优化概述

系统设置页面经过重新设计，采用现代化的双栏布局，提供更好的用户体验和更清晰的功能分组。

## 主要改进

### 1. 页面布局优化
- **双栏布局**：使用响应式网格布局，大屏幕显示双栏，小屏幕自动切换为单栏
- **功能分组**：将设置项分为"基本信息"和"安全设置"两个主要类别
- **视觉层次**：清晰的标题、描述和操作区域划分

### 2. 基本信息设置区域

#### 平台名称设置
- **标签说明**：清晰的标签和描述文字
- **输入框优化**：标准化的输入框样式
- **帮助文本**：说明平台名称的用途

#### Logo 管理
- **预览区域**：更大的Logo预览（24×24像素）
- **操作按钮**：垂直排列的操作按钮，更清晰的操作流程
- **文件信息**：详细的文件要求说明
- **状态反馈**：上传状态和错误信息的优化显示

### 3. 安全设置区域

#### 水印功能配置
- **开关设计**：右侧开关，左侧说明文字
- **功能描述**：清晰说明水印的作用
- **文本输入**：水印文本的自定义输入
- **实时预览**：优化的水印效果预览

### 4. 交互优化

#### 按钮设计
- **保存按钮**：独立的大尺寸保存按钮
- **操作反馈**：加载状态和成功提示的优化
- **错误处理**：更好的错误信息显示

#### 响应式设计
- **移动端适配**：在小屏幕上自动切换为单栏布局
- **触摸友好**：按钮和交互元素适合触摸操作

## 设计原则

### 1. 信息架构
- **逻辑分组**：相关功能放在同一区域
- **视觉层次**：使用颜色、大小、间距建立清晰的视觉层次
- **操作流程**：符合用户的操作习惯和认知模式

### 2. 用户体验
- **直观性**：界面元素的功能一目了然
- **一致性**：保持与系统其他页面的设计一致性
- **可访问性**：支持键盘导航和屏幕阅读器

### 3. 响应式设计
- **断点设计**：在大屏幕（lg:1024px+）显示双栏，小屏幕显示单栏
- **内容适配**：内容在不同屏幕尺寸下都能良好显示
- **交互优化**：触摸设备上的交互体验优化

## 技术实现

### 1. 布局技术
- **CSS Grid**：使用 `grid-cols-1 lg:grid-cols-2` 实现响应式双栏
- **Flexbox**：用于内部元素的排列和对齐
- **Tailwind CSS**：使用工具类快速构建界面

### 2. 组件设计
- **Card 组件**：使用 Shadcn UI 的 Card 组件
- **表单控件**：Input、Switch、Button 等标准化组件
- **图标系统**：使用 Lucide React 图标库

### 3. 状态管理
- **本地状态**：使用 React useState 管理表单状态
- **加载状态**：显示操作进度和反馈
- **错误处理**：优雅的错误信息显示

## 使用指南

### 1. 基本信息设置
1. **平台名称**：输入显示在页面标题和导航栏中的平台名称
2. **Logo 管理**：
   - 点击"选择新 Logo"上传新图片
   - 点击"恢复默认 Logo"使用系统默认 Logo
   - 查看文件要求和建议尺寸

### 2. 安全设置
1. **水印开关**：开启或关闭文件预览水印功能
2. **水印文本**：输入自定义水印文本，留空则显示用户名
3. **预览效果**：实时查看水印的显示效果

### 3. 保存设置
- 点击右下角的"保存设置"按钮
- 等待保存完成，系统会显示成功提示
- 设置立即生效，无需重启系统
