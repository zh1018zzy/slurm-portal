## 同步策略

### 1. 页面加载时的同步策略

**优先级顺序：**
1. **优先同步squeue中的活跃作业**：确保当前运行和等待的作业状态是最新的
2. **然后同步最近7天的所有作业**：更新历史作业的最终状态

**实现方式：**
- 页面首次加载时自动执行完整同步
- 使用 `fullSync=true` 参数触发完整同步
- 分两步执行：先活跃作业，再历史作业

### 2. 自动同步机制

**智能同步Hook：**
- 延迟5秒启动自动同步，避免与页面初始同步冲突
- 每2分钟检查一次活跃作业状态
- 页面可见性变化时自动启停同步

**同步条件：**
- 检测到活跃作业时自动同步
- 页面重新获得焦点时同步
- 后台定时检查

### 3. 手动同步功能

**智能同步按钮：**
- 只同步活跃作业的状态变化
- 快速响应，适合频繁使用

**强制同步按钮：**
- 同步最近7天所有作业的状态
- 包括已完成、失败、取消的作业
- 适合需要完整状态更新的场景

## 技术实现

### 1. 作业列表API (`/api/jobs`)

**同步流程：**
```typescript
// 1. 检查是否需要同步
if (!skipSync && autoSync) {
  // 2. 优先同步squeue中的活跃作业
  if (activeJobs.length > 0) {
    // 执行活跃作业同步
  }
  
  // 3. 然后同步最近7天的所有作业
  if (forceSync || fullSync) {
    // 执行完整同步
  }
}
```

**参数说明：**
- `skipSync=true`：跳过同步
- `autoSync=false`：禁用自动同步
- `forceSync=true`：强制同步
- `fullSync=true`：完整同步（最近7天）

### 2. 智能同步API (`/api/jobs/smart-sync`)

**同步逻辑：**
```typescript
// 1. 检查活跃作业
const { hasActive, activeJobIds } = await checkActiveJobs()

// 2. 根据模式执行同步
if (force) {
  // 强制模式：同步最近7天所有作业
  await smartStatusUpdate(activeJobIds, true)
} else {
  // 智能模式：只同步活跃作业
  await smartStatusUpdate(activeJobIds, false)
}
```

**状态更新：**
- 使用 `squeue` 获取活跃作业状态
- 使用 `sacct` 获取历史作业状态
- 批量更新数据库
- 清除相关缓存

### 3. 前端同步Hook (`useSmartJobSync`)

**自动同步：**
- 延迟5秒启动，避免冲突
- 每2分钟检查一次
- 页面可见性变化时启停

**手动同步：**
- `performSync()`：智能同步
- `forceSync()`：强制同步
- 实时状态反馈

## 同步效果

### 1. 页面加载体验

**首次加载：**
- 立即显示数据库中的作业列表
- 后台执行完整同步
- 同步完成后自动刷新显示最新状态

**后续访问：**
- 快速显示缓存数据
- 智能检查活跃作业
- 按需同步状态变化

### 2. 状态准确性

**活跃作业：**
- 实时同步squeue状态
- 状态变化立即反映
- 支持新作业自动发现

**历史作业：**
- 定期同步sacct状态
- 更新最终状态（完成/失败/取消）
- 保持历史记录完整性

### 3. 性能优化

**缓存策略：**
- 数据库缓存作业信息
- 前端缓存同步状态
- 智能清除过期缓存

**同步频率：**
- 活跃作业：实时同步
- 历史作业：按需同步
- 自动同步：2分钟间隔

## 使用说明

### 1. 页面操作

**自动同步：**
- 页面加载时自动执行
- 无需手动操作
- 状态实时更新

**手动同步：**
- 点击"智能同步"：快速更新活跃作业
- 点击"强制同步"：完整更新所有作业
- 同步完成后自动刷新列表

### 2. 参数控制

**跳过同步：**
```
/api/jobs?skipSync=true
```

**禁用自动同步：**
```
/api/jobs?autoSync=false
```

**强制完整同步：**
```
/api/jobs?forceSync=true&fullSync=true
```

### 3. 监控状态

**同步状态显示：**
- 活跃作业数量
- 上次同步时间
- 同步进度指示

**错误处理：**
- 同步失败时显示错误信息
- 自动重试机制
- 降级到数据库数据

## 优势特点

1. **分层同步**：优先活跃作业，再历史作业
2. **智能检测**：自动识别需要同步的作业
3. **性能优化**：避免不必要的同步操作
4. **用户体验**：快速响应，实时更新
5. **错误容错**：同步失败时不影响基本功能
