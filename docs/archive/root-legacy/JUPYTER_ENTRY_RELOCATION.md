> 适用范围：项目文档知识沉淀与协作参考

> 文档状态：`archived`

## 📋 变更说明

根据用户反馈,已将 **Jupyter Lab** 的入口从系统桌面首页调整到 **应用中心(HPC应用页面)**。

---

## 🔄 变更内容

### 移除位置
- ❌ **系统桌面首页** (`/dashboard`)
  - 移除了"AI工具"卡片
  - 移除了Jupyter Lab、PyTorch、vLLM的快捷入口

### 新增位置
- ✅ **应用中心** (`/dashboard/applications/hpc`)
  - 在页面顶部添加"AI开发工具"专区
  - 添加醒目的Jupyter Lab快捷卡片
  - 使用橙色主题区分AI工具和HPC应用

---

## 📍 新的访问路径

用户现在可以通过以下路径访问Jupyter Lab:

1. **主菜单** → 应用 → HPC应用中心
2. 在页面顶部找到 **"AI开发工具"** 区域
3. 点击 **Jupyter Lab** 卡片
4. 进入Jupyter Lab管理页面

或者直接访问:
```
/dashboard/jupyter
```

## ✅ 优势

将Jupyter Lab放在应用中心的好处:

1. **分类更清晰** - AI工具和HPC应用都在应用中心,符合用户心智模型
2. **避免首页拥挤** - 保持首页简洁,专注于核心功能(作业管理)
3. **便于扩展** - 未来添加更多AI工具时,统一在应用中心管理
4. **视觉区分** - 使用橙色主题突出AI工具,易于识别
