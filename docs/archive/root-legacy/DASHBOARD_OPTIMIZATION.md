## 🎨 设计理念

延续登录页面的**绿色科技风格**，对 Dashboard 的侧边栏、顶部导航栏和相关组件进行全面优化，打造统一的视觉体验。

---

## ✨ 核心优化内容

### 1. **侧边栏 Logo 品牌优化**

#### 🔹 绿色渐变 Logo
- Logo 容器：`bg-gradient-to-br from-green-500 via-emerald-600 to-teal-600`
- 外圈脉冲效果：`from-green-400/20 to-emerald-400/20`
- Hover 时光晕增强
- 阴影效果：`shadow-green-500/20` → `shadow-green-500/40`

#### 🔹 品牌文字渐变
- 三色渐变：`from-green-400 via-emerald-400 to-teal-400`
- Hover 颜色变浅效果
- 平滑过渡动画（300ms）

#### 🔹 图片 Logo 增强
- 添加绿色光环边框：`ring-green-400/30`
- Hover 时边框增强：`ring-green-400/60`
- 保持圆角和模糊效果

---

### 2. **导航菜单项现代化**

#### 🔹 活跃状态
```css
/* 背景渐变 */
bg-gradient-to-r from-green-500/10 to-emerald-500/10

/* 文字颜色 */
text-green-600 dark:text-green-400

/* 左侧边框装饰 */
border-l-2 border-green-500

/* 右侧装饰条 */
w-1 h-5 bg-gradient-to-b from-green-400 to-emerald-500
```

#### 🔹 Hover 效果
- 背景：`hover:bg-green-500/5`
- 文字：`hover:text-green-600 dark:hover:text-green-400`
- 图标缩放：`group-hover:scale-110`
- 颜色过渡：`transition-all duration-300`

#### 🔹 视觉层次
- 活跃项左侧 2px 绿色边框
- 右侧渐变装饰条（非折叠时）
- 微妙的阴影效果
- 图标动态响应

---

### 3. **顶部导航栏增强**

#### 🔹 边框装饰
- 底部边框：`border-green-500/10`
- 顶部装饰条：`bg-gradient-to-r from-transparent via-green-400/50 to-transparent`
- 微妙阴影：`shadow-sm`

#### 🔹 背景优化
- 保持毛玻璃效果：`backdrop-blur`
- 半透明背景：`bg-background/95`
- 支持 backdrop-filter

---

### 4. **大屏按钮改版**

// 阴影

#### 🔹 加载状态
- 旋转加载圈：绿色边框
- 保持渐变背景
- 禁用时的视觉反馈
