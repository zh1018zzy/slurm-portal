# 文件预览水印功能

> 适用范围：系统模块长期知识（认证、权限、许可证、作业同步等）
> 主入口链接：`docs/README.md`
> 文档状态：`active`
> 最后验证日期：`2026-03-27`

## 功能概述

文件预览水印功能为系统中的文件预览添加了安全保护，可以在预览的文件内容上显示水印，防止文件内容被恶意复制或传播。

## 主要特性

### 1. 智能水印显示
- **默认显示用户名**：如果未设置自定义水印文本，自动显示当前用户名
- **自定义水印文本**：管理员可以设置统一的水印文本
- **全局开关控制**：可以全局启用或禁用水印功能

### 2. 水印样式设计
- **多水印分布**：页面显示多个水印，覆盖不同区域
- **半透明效果**：水印透明度适中，不影响文件内容阅读
- **旋转角度**：水印以45度角旋转显示，增加视觉效果
- **重复背景**：使用重复的斜线背景增强水印效果
- **不可选择**：水印文本不可被用户选择或复制
- **大小变化**：不同位置的水印使用不同字体大小，增加层次感

### 3. 应用范围
- **文件管理页面**：`/dashboard/files` 的文件预览
- **作业管理页面**：`/dashboard/jobs/[id]` 的文件预览
- **支持的文件类型**：
  - 文本文件（代码、日志等）
  - 图片文件
  - PDF文件

## 配置说明

### 系统设置页面配置

在 `/dashboard/system/settings` 页面可以配置水印功能：

#### 1. 水印开关
- **启用水印**：开启或关闭水印功能
- **默认状态**：系统默认启用水印

#### 2. 水印文本设置
- **留空**：显示当前用户名作为水印
- **自定义文本**：输入统一的水印文本
- **示例**：`公司机密`、`内部文件`、`仅供查看`等

#### 3. 实时预览
- 在设置页面提供水印效果预览
- 可以实时查看水印的显示效果

## 技术实现

### 1. 水印组件 (`components/Watermark.tsx`)
```typescript
interface WatermarkProps {
  children: React.ReactNode;
  username: string;
  watermarkText?: string;
  watermarkEnabled?: boolean;
}
```

### 2. 水印样式
- **CSS样式**：使用CSS3的transform和opacity属性
- **多水印布局**：使用绝对定位在页面不同位置显示水印
- **背景图案**：重复的斜线背景增强视觉效果
- **响应式设计**：适配不同屏幕尺寸
- **层次设计**：不同位置使用不同字体大小和透明度

### 3. 系统集成
- **系统设置API**：`/api/system/settings` 支持水印配置
- **配置文件**：`config/system-settings.json` 存储水印设置
- **组件复用**：水印组件可在多个页面复用

## 使用场景

### 1. 企业文档保护
- 防止内部文档被截图传播

- 增加文档安全性

### 2. 代码审查
- 在代码预览中显示审查者信息
- 防止代码被未授权复制
- 追踪代码查看记录

### 3. 日志文件查看
- 在日志预览中显示查看者
- 防止敏感日志信息泄露

## 配置示例

### 1. 显示用户名水印
```json
{
  "watermarkEnabled": true,
  "watermarkText": ""
}
```
效果：显示当前用户名作为水印

### 2. 自定义文本水印
```json
{
  "watermarkEnabled": true,
  "watermarkText": "公司机密文件"
}
```
效果：显示"公司机密文件"作为水印

### 3. 禁用水印
```json
{
  "watermarkEnabled": false,
  "watermarkText": ""
}
```
效果：不显示任何水印

## 安全考虑

### 1. 水印强度
- **视觉强度**：水印透明度适中，不影响阅读
- **覆盖密度**：多个水印覆盖页面不同区域，增加保护强度
- **技术强度**：使用CSS样式，难以通过简单方法移除
- **覆盖范围**：水印覆盖整个预览区域，无死角保护

### 2. 用户体验
- **不影响阅读**：水印不会干扰正常文件内容阅读
- **性能优化**：水印组件轻量级，不影响页面性能
- **响应式设计**：适配不同设备和屏幕尺寸

### 3. 管理控制
- **管理员权限**：只有管理员可以修改水印设置
- **全局控制**：水印设置影响所有用户的预览
- **实时生效**：设置修改后立即生效

## 最佳实践

### 1. 水印文本建议
- **简洁明了**：使用简短、清晰的水印文本
- **信息丰富**：包含必要的标识信息
- **易于识别**：确保水印文本清晰可读

### 2. 配置建议
- **默认启用**：建议默认启用水印功能
- **定期更新**：根据安全需求定期更新水印文本
- **用户培训**：向用户说明水印的作用和意义

### 3. 监控和维护
- **效果检查**：定期检查水印显示效果
- **用户反馈**：收集用户对水印功能的反馈
- **安全评估**：定期评估水印功能的安全效果

## 注意事项

1. **浏览器兼容性**：水印功能依赖现代CSS特性，建议使用现代浏览器
2. **性能影响**：水印组件对页面性能影响很小，但大量文件预览时需注意
3. **用户隐私**：水印会显示用户名，需确保符合隐私政策
4. **配置备份**：建议定期备份水印配置设置
